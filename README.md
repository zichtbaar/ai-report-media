# ai-report-media

Openbare opslag voor social-media-bestanden van AI Report (carrousels, afbeeldingen, video's), zodat Buffer ze via een directe link kan ophalen.
Bron en werkwijze: projectmap `ai-report-social` (zie AGENTS.md daar). Alleen bestanden die gepubliceerd worden; geen werkbestanden of privé-materiaal.

Structuur: `<datum>_<onderwerp>/` per post. Directe link: `https://raw.githubusercontent.com/zichtbaar/ai-report-media/main/<pad>`
